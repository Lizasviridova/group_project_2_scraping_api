# Описание и бизнес-задача:
Наш проект представляет из себя анализ того, какие факторы делают новость популярной, когда лучше выкладывать новость. Наш анализ может помочь компаниям оптимизировать свои пресс-релизы и взаимодействие с журналистами, сделать его более грамотным, а не просто выкладывание новсти ради процесса.

# Проблема, на основании которой возникла идея нашего проекта: 
есть компании, котоые тратят свой бюджет на создание новостей, контента, рассылки пресс-релизов, но делают это неграмотно, не понимают какие темы, заголов, ключевые слова больше привлекают аудиторию, читателей.

# Цель нашего проекта:
1. Создать датасет из двух источников: парсинг и API, который далее будем анализировать
2. проанализировать какие загаловки, ключевые слова помогпомогат новости стать более читаемой
3. поянть, как размер новости (длина текста и заголовка) можем быть связан с пополучрностью новости
4. понять, какие источники дают лучший охват

# Описание полей в источниках

**Парсинг:**

title - заголовок новости 

content - текст новости

link - ссылка на новость

date - дата публикации новости

source_type - м ожет принимать следующие значения: website или "второй источник"

sours_name - откуда взята новость, может быть либо tass.ru (новость взята с сайта ТАСС) либл "тут будет второй источник"

**API**:

id_post - идентификатор поста в тг

date - дата публикации поста/новости

text - текст, описание поста/новости

views - количество просмотров поста/новости

reactions_count - количество реакций на посте/новости

reactions_detail - какие реакции ставили у поста/новости и в каком количестве

forwards - количество репостов поста/новости

has_media - флаг, отвечающий за наличие медиа у поста/новости. Если медиа есть, то значение 1, если нет, то значение 0

media_type - если у поста/новости есть медиа, то будет категория медиа (photo, video), если нет, то будет написано no_media

links - ссылки в посте/новости на саму новость

post_url - ссылка поста/новости в тг

**Целевая переменная:**

В парсинге - переменная content (текст новости/поста)

В API - переменная text (текст новости/поста)
